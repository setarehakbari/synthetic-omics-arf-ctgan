# Synthetic Omics: ARF, CTGAN, and TVAE

This repository contains code, synthetic datasets, and analysis outputs associated with the manuscript:

**“Balancing Utility and Privacy: Evaluating Synthetic Gene Expression Data with a Novel Dilution Metric for Feature Stability.”**

The study evaluates synthetic gene-expression data generated using Adversarial Random Forest (ARF), Conditional Tabular GAN (CTGAN), and Tabular Variational Autoencoder (TVAE). The evaluation framework considers six complementary dimensions: predictive utility, statistical fidelity, privacy-related distinguishability, feature-importance alignment, dilution of real-data feature rankings, and bootstrap feature-selection stability.

## Repository structure

- `R/`: R scripts used for preprocessing, statistical analyses, evaluation, figures, and tables.
  - `R/preprocess_real_data.R`: reproduces quantile normalization, log2 transformation, coefficient-of-variation (CoV) filtering, zero-variance feature removal, and construction of the final sample-by-gene analysis matrix for researchers with authorized access to the source data.
  - `R/evaluate_all_generators.R`: primary evaluation pipeline for ARF, CTGAN, and TVAE.
  - `R/topk_sensitivity_analysis.R`: evaluates sensitivity of feature-alignment and dilution measures to K = 25, 50, and 100 using the fixed full feature rankings from the primary analysis.
  - Table 2 in the manuscript is based on the ranking-agreement and dilution results in `results/07_ranking_dilution_summary_K50.csv`, generated by `R/evaluate_all_generators.R`.

- `generators/`: scripts used for synthetic-data generation.
  - `ARF_generate.R`: ARF synthetic-data generation script.
  - `CTGAN_generate.py`: CTGAN training and synthetic gene-expression generation.
  - `TVAE_generate.py`: TVAE training and synthetic gene-expression generation.

- `quantum/`: Python scripts used for the exploratory quantum-adversarial extension described in the manuscript.

- `results/`: generated tables and analysis outputs associated with the manuscript, including the Top-K sensitivity-analysis results.

- `synthetic_data/`: archived synthetic datasets used in the manuscript analyses for ARF, CTGAN, and TVAE.

## Synthetic-data generation and provenance

The repository includes the synthetic datasets used in the manuscript evaluation for ARF, CTGAN, and TVAE.

The archived ARF (`synthetic_rna_arf.csv`) and CTGAN (`synthetic_ctgan.csv`) files are the fixed synthetic datasets used to produce the reported manuscript results. The TVAE dataset (`synthetic_rna_tvae.csv`) was generated for the revised analysis and evaluated using the same downstream framework.

Generation scripts are provided separately under `generators/`. Because synthetic-data generation is stochastic, rerunning a generator may produce a valid dataset that is not byte-identical to the archived dataset used for the manuscript. Regenerated outputs should therefore be written to separate filenames and should not overwrite the archived evaluation datasets.

Dataset-provenance records and checksums are provided in the repository to support verification of the synthetic datasets used for the reported analyses.

## Feature-ranking and dilution analysis

The feature-ranking analysis compares feature-importance rankings derived from the real data with rankings obtained from synthetic and real-plus-synthetic datasets.

The following complementary measures are evaluated:

- Spearman's rank correlation
- Kendall's rank correlation
- Rank-Biased Overlap (RBO; p = 0.95)
- Top-K Jaccard similarity
- Mean absolute rank shift
- Median absolute rank shift
- Top-K dropout

The primary manuscript analysis uses K = 50. Mean absolute rank shift is used as the primary summary of dilution magnitude, while signed rank displacement can be retained as a secondary directional summary.

Dilution is calculated using Random Forest permutation-importance rankings. NPDR is evaluated separately as an alternative feature-relevance method.

## Top-K sensitivity analysis

To assess sensitivity to the selected Top-K threshold, feature-alignment and dilution analyses were additionally evaluated at K = 25 and K = 100, with K = 50 retained as the primary manuscript setting.

The sensitivity calculations reuse the fixed full RF and NPDR feature rankings generated in the primary analysis; therefore, no RF or NPDR models are refit. The sensitivity implementation was validated by exact reproduction of the primary K = 50 results before application to K = 25 and K = 100.

The main qualitative patterns were broadly consistent across thresholds, although the magnitude of feature overlap and rank displacement varied with K. Complete sensitivity-analysis outputs are available in:

`results/topk_sensitivity_K25_K50_K100.csv`

Bootstrap stability was retained at K = 50 because the original bootstrap analysis stored replicate-level stability summaries rather than complete feature rankings, and evaluation at additional K values would require rerunning the full resampling procedure.

## Data availability

The real gene-expression dataset is not included in this repository because of data-use restrictions.

The repository provides the preprocessing, synthetic-data generation, and evaluation code required to reproduce the computational workflow for researchers with authorized access to the underlying real data. Synthetic datasets and derived analysis outputs used in the manuscript are provided where permitted.

## Notes on reproducibility

Unless otherwise specified, the revised analyses use a base random seed of 42, with deterministic seed offsets applied across repeated model fits and resampling procedures.

The archived synthetic datasets should be used when reproducing the numerical results reported in the manuscript. Generation scripts are provided to document and enable rerunning the corresponding synthetic-data generation procedures, but regenerated outputs should not be assumed to be byte-identical to the archived manuscript datasets because synthetic-data generation is stochastic.

The repository also includes evaluation settings, software-session information, and dataset-provenance records used to document the revised computational workflow.

## Software

The primary evaluation pipeline uses R, while CTGAN, TVAE, and the quantum-adversarial extension use Python.

Detailed software versions, package versions, model hyperparameters, random-seed settings, and evaluation parameters are reported in the revised manuscript and corresponding scripts.
