# Dataset provenance for the revised manuscript

This repository distinguishes between the archived synthetic datasets used for the manuscript evaluation and regenerated outputs produced only to demonstrate that the generation pipelines run successfully.

## Canonical evaluation inputs

| Dataset | Canonical filename | Rows × columns | Class counts (HC/MDD) | Role in revised manuscript | MD5 |
|---|---|---:|---:|---|---|
| Real | `gene_with_label.csv` | 157 × 1784 | 79 / 78 | Preprocessed real gene-expression data used as the common reference dataset | Not distributed publicly because of data-use restrictions |
| ARF | `synthetic_rna_arf.csv` | 200 × 1784 | 95 / 105 | **Archived/canonical ARF synthetic dataset used for all manuscript evaluation analyses** | `24ee0d628ff7a1dfd5f6ebf66a2bd358` |
| CTGAN | `synthetic_ctgan.csv` | 200 × 1784 | 103 / 97 | **Archived/canonical CTGAN synthetic dataset used for all manuscript evaluation analyses** | `630050778c8a36eb65f507d42c607c7c` |
| TVAE | `synthetic_rna_tvae.csv` | 200 × 1784 | 103 / 97 | TVAE synthetic dataset added during revision and used in the expanded three-generator evaluation | `279052ce8e8e9bd154e526c6d7814a94` |

All synthetic datasets contain the same 1,783 gene-expression features plus the binary class variable.

## Important distinction: archived vs regenerated ARF

`synthetic_rna_arf_regenerated.csv` is **not** the ARF dataset used for the manuscript results.

It was generated by the cleaned `generators/ARF_generate.R` script as a reproducibility check. Because ARF generation is stochastic, this regenerated dataset is not expected to be byte-identical to the archived manuscript dataset. In the successful reproducibility run, the regenerated ARF dataset contained 200 observations with class counts 98/102, whereas the archived/canonical ARF dataset used in the manuscript contains class counts 95/105.

Accordingly:

- `synthetic_rna_arf.csv` → use for manuscript evaluation and reported results.
- `synthetic_rna_arf_regenerated.csv` → use only to demonstrate that the generation pipeline executes successfully; do not substitute it for the archived manuscript dataset.

The same principle applies to any regenerated CTGAN output: regenerated files should not overwrite or replace the archived CTGAN dataset used in the manuscript evaluation.

## Evaluation provenance

The unified evaluation script should read exactly these three synthetic-data files:

```r
arf_path  <- file.path(base_dir, "synthetic_rna_arf.csv")
ctg_path  <- file.path(base_dir, "synthetic_ctgan.csv")
tvae_path <- file.path(base_dir, "synthetic_rna_tvae.csv")
```

The completed revision analysis used these archived/canonical inputs and produced the three-generator results for utility, UMAP visualization, statistical fidelity, privacy-related distinguishability, RF and NPDR feature alignment, dilution/rank agreement, and bootstrap feature-selection stability.

## Suggested README wording

### Synthetic data and provenance

The repository includes the synthetic datasets used in the manuscript evaluation for ARF, CTGAN, and TVAE. The archived ARF (`synthetic_rna_arf.csv`) and CTGAN (`synthetic_ctgan.csv`) files are the fixed synthetic datasets used to produce the reported manuscript results. The TVAE dataset (`synthetic_rna_tvae.csv`) was generated for the revised analysis and evaluated using the same downstream framework. Generation scripts are provided separately under `generators/`. Because synthetic-data generation is stochastic, rerunning a generator may produce a valid dataset that is not byte-identical to the archived dataset used for the manuscript. Regenerated outputs are therefore written to separate filenames and should not overwrite the archived evaluation datasets.
